# Задача 2: Реализация МП автомата для контекстно-свободного языка

## 1. Задание

1. Построить порождающую грамматику для заданного КС языка.

2. Разработать распознающий МП автомат для цепочек определенного в задании КС языка над заданным алфавитом и реализовать его в виде подпрограммы.

3. Разработать программу, распознающую цепочки этого языка на основе программной реализации МП автомата.

**Вход:** последовательность символов алфавита языка задания

**Выход:** «цепочка принадлежит языку» или  
«Ошибка: в позиции номер неожидаемый символ символ»

номер – номер позиции, в которой стоит неожидаемый символ

## 2. Пример:

Язык: {0^n 2 1^n | n ≥ 0}. Алфавит языка {0, 1, 2}

Вход: `0011`

Выход: «Ошибка: в позиции 3 неожидаемый символ 1»

Реализация осуществляется на любом языке программирования.

## 3. Язык:

{a^m 0 b^n 0 a^m | n, m ≥ 0}, алфавит {0, a, b}

---

# Решение

## 1. КС грамматика

Заданный язык описывается контекстно-свободной грамматикой G = (N, T, P, S), где:

- **N = {S, B}** — множество нетерминальных символов;
- **T = {0, a, b}** — множество терминальных символов (алфавит);
- **S** — начальный нетерминальный символ;
- **P** — множество правил вывода.

**Правила вывода P:**

S → aSa | 0B0
B → bB | ε

где ε обозначает пустую строку.

**Пояснение правил:**

- Правило `S → aSa` обеспечивает симметричное добавление символов 'a' с обеих сторон от центральной части, что гарантирует равенство количества 'a' в начале и в конце цепочки.
- Правило `S → 0B0` задает разделители '0' и переходит к генерации центральной части.
- Правило `B → bB` генерирует произвольное количество символов 'b'.
- Правило `B → ε` завершает генерацию цепочки (с учётом n = 0).

**Пример вывода цепочки aa0bb0aa (m = 2, n = 2):**

S ⇒ aSa ⇒ aaSaa ⇒ aa0B0aa ⇒ aa0bB0aa ⇒ aa0bbB0aa ⇒ aa0bb0aa


## 2. Формальное задание МП автомата

Магазинный автомат (МП) задается:

**M = (Q, Σ, Γ, δ, q0, Z0, F)**, где:

- **Q = {q0, q1, q2, q3, q4, q5}** — конечное множество состояний;
- **Σ = {0, a, b}** — входной алфавит;
- **Γ = {a, Z0}** — алфавит стека (Z0 — начальный символ стека);
- **q0** — начальное состояние;
- **Z0** — начальный символ стека;
- **F = {q5}** — множество допускающих состояний;
- **δ** — функция переходов.

**Функция переходов δ:**

| Состояние | Символ | Стек | → Состояние | Стек |
|-----------|--------|------|-------------|------|
| q0 | a | Z0 | q0 | aZ0 |
| q0 | a | a | q0 | aa |
| q0 | 0 | Z0 | q1 | Z0 |
| q0 | 0 | a | q1 | a |
| q1 | b | Z0 | q2 | Z0 |
| q1 | b | a | q2 | a |
| q1 | 0 | Z0 | q3 | Z0 |
| q1 | 0 | a | q3 | a |
| q2 | b | Z0 | q2 | Z0 |
| q2 | b | a | q2 | a |
| q2 | 0 | Z0 | q3 | Z0 |
| q2 | 0 | a | q3 | a |
| q3 | a | a | q4 | ε |
| q3 | ε | Z0 | q5 | Z0 |
| q4 | a | a | q4 | ε |
| q4 | ε | Z0 | q5 | Z0 |

**Описание работы автомата:**

- **Состояние q0:** чтение первых символов 'a' и помещение их в стек.
- **Состояние q1:** прочитан первый разделитель '0'.
- **Состояние q2:** чтение символов 'b' (стек не изменяется).
- **Состояние q3:** прочитан второй разделитель '0'. Если стек пуст, автомат переходит в допускающее состояние q5 (случай m=0).
- **Состояние q4:** чтение вторых символов 'a' и удаление соответствующих 'a' из стека.
- **Состояние q5:** допускающее состояние (стек пуст, цепочка принята).

Автомат допускает цепочку, если после обработки всей входной строки он находится в состоянии q5.

## 3. Краткое описание работы подпрограммы, реализующей МП автомат, и программы распознавания цепочек языка

Подпрограмма, реализующая магазинный автомат (МП), выполняет распознавание входной строки на принадлежность заданному контекстно-свободному языку {a^m 0 b^n 0 a^m | n, m >= 0}. Автомат использует стек для подсчёта количества символов 'a' в начале строки и их последующего сопоставления с символами 'a' в конце строки.

**Принцип работы автомата:**

1. В начальном состоянии q0 автомат читает символы 'a' и помещает их в стек.
2. При встрече первого символа '0' автомат переходит в состояние q1, фиксируя конец первой группы 'a'.
3. В состоянии q1 и q2 автомат читает символы 'b' (любое количество, включая ноль), не изменяя стек.
4. При встрече второго символа '0' автомат переходит в состояние q3, фиксируя конец группы 'b'.
5. В состоянии q3 и q4 автомат читает символы 'a' и для каждого из них удаляет один символ 'a' из стека.
6. Если после обработки всей строки автомат находится в допускающем состоянии q5, цепочка признаётся принадлежащей языку.

**Программа распознавания цепочек языка выполняет следующие действия:**

1. Считывает входную строку от пользователя.
2. Проверяет каждый символ на принадлежность алфавиту {0, a, b}. При обнаружении недопустимого символа программа выводит сообщение об ошибке с указанием его позиции и завершает работу.
3. Если алфавит корректен, передаёт строку в подпрограмму МП автомата.
4. Автомат обрабатывает строку посимвольно, выполняя переходы согласно таблице переходов и операции со стеком.
5. Если автомат завершает работу в допускающем состоянии при полностью прочитанной строке, программа выводит «цепочка принадлежит языку».
6. В противном случае программа выводит сообщение об ошибке с указанием позиции и неожидаемого символа.
